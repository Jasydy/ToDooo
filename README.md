# ToDooo (Flutter)

Простое приложение-окно со списком дел:
- можно ввести задачу в поле;
- нажать кнопку **Добавить**;
- задача появится в списке ниже.

## Как запустить

1. Установить Flutter: https://docs.flutter.dev/get-started/install
2. В папке проекта выполнить:

```bash
flutter pub get
flutter run
```

Для Windows запустится desktop-приложение, для iPhone — iOS-приложение (на macOS с Xcode).
